로컬 DB 데이터를 활용한 자유로운 시각화

자동 데이터 로딩 개선: 기존에는 체크박스를 클릭해야만 데이터셋이 로드되었지만, 이제 목록에서 행을 클릭(하이라이트) 하기만 해도 선택된 것으로 간주하여 데이터를 자동으로 로드합니다.

프롬프트 기반 시각화: LLM이 사용자의 시각화 요구를 분석해, 선택된 데이터셋으로 원하는 그래프를 생성합니다.

예: “시간, MPT, R_LP 3차원 시각화”라고 입력하면, 자동으로 시간·MPT·R_LP 컬럼으로 3D 산점도를 그리고 ‘시각화 결과’ 탭에 표시합니다.

예: “전체 시간에 대해 MPT, R_RS 그래프를 그려줘”라고 입력하면, 시간 축에 여러 Y 변수(MPT, R_RS)를 그린 다중 라인 차트가 표시됩니다.

다양한 변수 인식: 변수명은 데이터프레임의 실명 혹은 축약형을 대소문자 구분 없이 인식합니다. “time”, “시간”, “mpt”, “r_lp” 등 공정 데이터를 표현하는 주요 컬럼명을 알아서 찾아줍니다.

🔧 추가 개선 사항

기존의 상관관계, 3D 경로, MPT-시간 그래프 기능도 유지되며, 키워드(“상관관계”, “경로”, “MPT 시간”)를 통해 호출할 수 있습니다.

선택/업로드 없이도 로컬 DB의 데이터로 그래프를 그릴 수 있도록 ensure_dataset_loaded()가 강화되었습니다.

시각화 오류 메시지가 더욱 구체적으로 변경되어, 원인을 쉽게 파악할 수 있습니다.

해당 패치를 적용한 후, 사용자는 LLM 탭에서 다음과 같이 활용할 수 있습니다:

여러 데이터를 선택 후 “시간, MPT, R_LP 3차원 시각화”라고 입력 → 3D 산점도

“전체 시간에 대해 MPT, R_RS, R_WS 그래프를 그려줘” → 다중 시계열 라인 그래프

“상관관계 분석 보여줘” → correlation heatmap

필요시 기존 기능(시뮬레이션, AW 등)은 동일하게 동작합니다.
